# How to Get the Hypotenuse of a Right Triangle

## Description
This program will ask you to input two numbers (side a, b) for a right triangle, and will calculate the hypotenuse: this is also how you can get the distance between two points.

## How to Run
1. Open the file with an IDE
2. Run the program.

## Input Needed
You are going to need to input two things:
1. side a 
2. side b

## Sample output
It'll always output c (distance or hypotenuse)
For example, you input 3 and 4 as your side a and side b. The output or the hypotenuse should be 5.
Another example, you can input 6 and 8 as your side a and b. The output or the distance should be 8.
